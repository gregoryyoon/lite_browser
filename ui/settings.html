Windows 10 및 11에서는 버튼 클릭 후 열리는 시스템 설정 창에서 Lite Browser를 기본 브라우저로 선택해 주시면 즉시 적용됩니다.

성능 및 메모리 최적화

사용 환경과 PC 사양에 맞춰 Chromium 런타임 엔진 동작 방식을 최적화합니다.

기본값 (권장)

GPU 하드웨어 가속 및 Zero-copy 타일 렌더링을 적용하여 초고속 페이지 로딩과 부드러운 스크롤링 및 화면 전환을 제공합니다.

--enable-gpu --enable-zero-copy --enable-gpu-rasterization Zero-Copy
현재 세션 적용 중 (기본값)
저사양 / 절전

사이트 격리 프로세스를 통합하고 렌더러 수를 최대 2개로 제한하며, V8 힙 상한(256MB) 및 메모리 절약 모드를 활성화하여 RAM 점유율을 대폭 낮춥니다.

--disable-site-isolation-trials --renderer-process-limit=2 --js-flags="256MB" MemorySaverMode --disable-extensions
미적용
브라우저 재시작 필요

최적화 모드 변경 사항은 브라우저를 완전히 닫고 다시 실행하면 적용됩니다.

Chromium 엔진 시작 파라미터가 조정되므로 설정 변경 후 브라우저를 재시작해야 새로운 옵션이 적용됩니다. 일반 환경에서는 실행 속도 우선을 권장합니다.
